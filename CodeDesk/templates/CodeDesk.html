Como formatar a submissão

O CodeGrader processa as submissões lendo os nomes e cabeçalhos dos arquivos dos alunos, mas exige uma pasta separada para os gabaritos da prova.

1. Pasta de Gabaritos (Obrigatório)
O arquivo ZIP deve conter uma pasta chamada gabaritos/. Dentro dela, coloque as soluções esperadas para cada problema (ex.: p01.c, p02.c).
2. Arquivos dos Alunos (Padrão de Nome)
Os arquivos dos alunos podem estar organizados em pastas ou soltos no ZIP, mas precisam seguir o padrão: a<id>q<questao>t<tentativa>.<extensao>.
Exemplo: a042820q02t01.c.
3. Cabeçalho de Metadados
O sistema busca dados nas 15 primeiras linhas do arquivo do aluno. Use os marcadores de comentário da sua linguagem (//, #, etc).
prova-01.zip/ ├── gabaritos/ <-- Pasta obrigatória │ ├── p01.c │ └── p02.c └── (Arquivos de alunos) <-- O sistema acha pelo nome ├── a042820q01t01.c └── a042820q02t01.c // Exemplo de cabeçalho lido do aluno: // Aluno: Ana Beatriz Lima 2823610045 (4735) // Questao: 2, 1a tentativa, nota: 9.8
